# v1.0.0 visual guide

The ZIP includes all 38 images below. These are actual application captures from the project lab, with the Branding live preview labelled as example data in the UI. The phone-navigation image compares the menu closed and open. No login forms, passwords, API keys, token values, or raw chat attachments are included. Lab object names and addresses remain visible.

Eight images were captured on 27 October against the release candidate. The other 30 are reviewed development captures and can show earlier breadcrumbs, navigation or filter layouts. Current routes are listed alongside each image so those captures can be refreshed before publication.
