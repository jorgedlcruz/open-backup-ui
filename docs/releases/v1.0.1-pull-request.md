# v1.0.1: Kiosk Builder, TV Dashboards & AI Reports

**Base:** `main` · **Head:** `features/v1.0.1`

## Summary

Open Backup UI v1.0.1 adds Kiosk Builder: an opt-in workspace for turning existing VBR evidence into personal dashboards and read-only monitoring screens. Draw a widget, choose its data, map names and values, then publish a view that fits a TV and refreshes automatically. The release also brings cached forecast previews, clearer AI configuration and provider errors, and a designed PDF export for completed health summaries.

## What's new

- **Kiosk Builder in Labs:** enable it under Settings, then compose a canvas with draw-to-create widgets, live previews, magnetic alignment, cascading repulsion, consistent padding, tidy/lock controls and undo/redo. Layouts save per browser and VBR source, with validated configuration import/export.
- **Sixteen VBR sources:** protection, job history and state, malware, security, repository capacity and forecasts, runway, backup footprint, retention, hygiene, operations, proxies, managed servers and license health. Existing read APIs and caches supply the evidence; missing and partial readings remain explicit.
- **Ten visual forms:** object cards, tables, donuts, pies, bars, lines, time series, KPIs, mosaics and radars. Choose categories, measures, calculations, columns, filters, UTC time buckets and visible series. Repository names accompany capacity values; job names resolve by source ID, with explicit fallback evidence.
- **Branding throughout:** console fonts, colours, density, corners and Glass surfaces, with a consistent Lucide icon family. Object grids support grouped objects or individual records with readable names, status, counts and timestamps.
- **Read-only sharing:** explicit publish/update/revoke, optional passwords and configurable auto refresh. The separate kiosk listener exposes viewer routes on another port or hostname and rejects management routes. Public responses contain projected display fields, not credentials or raw source snapshots.
- **TV mode:** full-screen tiling fits the available screen with padding; Saved arrangement preserves the original composition. Entering full screen enables refresh, controls hide when idle, and Escape returns to the regular viewer.
- **Cached planning on screen:** select a repository, forecast basis and 30/60/90-day horizon. Refresh reads the existing cache without triggering collection. The Protection Lens selector also gains a populated forecast miniature with repository and freshness context.
- **AI settings and diagnostics:** configuration saves work with local, LAN and proxy application URLs; save and catalog checks have separate feedback and timeouts. The themed summary panel shows sanitized provider errors, including Gemini credit failures and interrupted streams, with relevant next steps.
- **AI summary PDF:** export all completed summary sections as A4 or US Letter with a cover, linked contents, callouts, repeating table headers, page numbers and embedded multilingual fonts. Analysis notes are optional. Export runs in the browser without another provider request.

## Upgrade and behavior notes

- Back up persistent `data/` and its encryption key. Published links and password hashes live under `data/kiosk-shares/`; personal editor layouts remain in browser storage.
- Labs is disabled by default. The initial kiosk catalog covers VBR; Microsoft 365 and Veeam ONE are not included. Some new experimental copy uses English fallback.
- Configure `KIOSK_PUBLIC_ORIGIN` and run `npm run start:kiosk` to publish links. Keep the management listener on loopback or an appropriately protected network. The separate viewer listener does not add a console login or protect an independently exposed editor port.
- Shared data is not anonymized. Review visible fields and names before publishing; treat the full share URL as an access credential. Use HTTPS where required.
- Planning widgets preserve cache timestamps and freshness states. Screen refresh does not collect new planning evidence, and forecasts remain advisory.
- AI generation sends environment context to the configured provider. PDF export reuses the completed result locally; downloaded reports may contain that context. Provider catalog access does not establish inference compatibility or available credits.
