## Review before recapturing

- Capture the actual saved kiosk in the editor and its published read-only viewer. Keep source timestamps, missing evidence and partial-data notices visible.
- Include the empty canvas illustration and PDF miniature preview. Use a separate browser origin for the empty canvas so the existing composition is preserved, then restore that origin's Labs preference.
- Show both idle full-screen TV mode and its layout/refresh controls. Use the application controls to enter full screen; retain the captured framing and dimensions.
- Capture sharing controls before publishing or revealing an existing URL. Never include a usable kiosk token or enter a real password for a documentation image.
- Keep credential fields blank or masked. Review every pixel for tokens, connection secrets, personal identifiers and license identifiers. Lab resource names and addresses in this set are intentional.
- Identify earlier development captures rather than implying all images came from the final build. Keep the actual report body and downloaded PDF outside the repository; the curated cover is sufficient here.
- Convert reviewed captures to WebP under `docs/releases/images/v1.0.1/`. Leave raw captures, contact sheets and output in ignored directories.
- Restore temporary browser preferences and close capture tabs without modifying the user's saved board, share configuration or original tab.
