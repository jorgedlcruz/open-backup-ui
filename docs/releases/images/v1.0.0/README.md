# v1.0.0 documentation images

All 38 numbered images are included and referenced by the [release notes](../../v1.0.0.md), [visual guide](../../v1.0.0-gallery.md), and [capture checklist](../../v1.0.0-screenshots.md).

These are reviewed application screenshots, not raw chat attachments. Passwords, API keys, tokens, saved connection files, and license identifiers are excluded. Lab object names and addresses remain visible. The gallery identifies development captures that predate the final navigation/filter refinements.

Images use high-quality WebP to keep the portable Git repository small. New captures should use the same numbered filenames and be reviewed before committing.
