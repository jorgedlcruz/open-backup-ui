# v1.0.1 release images

Fifteen curated WebP assets for the [illustrated release](../../v1.0.1.md), [PR](../../v1.0.1-pull-request.md) and [visual guide](../../v1.0.1-gallery.md).

Nine current kiosk screenshots were captured on 1 November 2026. Six reviewed development captures cover cached forecasts, Gemini and AI/PDF presentation. The gallery records each date, route, dimensions and any earlier UI differences. The PDF cover is a rendering of the actual export; the export-dialog miniature is an application preview.

Images retain the original framing and dimensions and contain no added or removed UI elements. WebP compression uses quality 92. No raw PNGs, private PDF reports, access tokens, credentials or saved connection files belong in this directory. Lab resource names and addresses remain visible.
